# 开发档案：修复工作台误将临时进程识别为视频工坊端口漂移的问题

- **项目标识**：port-console
- **归档时间**：2026-11-03 22:24:41
- **关联提交**：77e5f6720a018ddf1589bb2c45579331b0728ea7

## 一、需求背景与目标
Video Farm 视频工坊打不开，页面提示端口漂移至 9999

## 二、现象排查与根因分析
后台遗留了运行在 9999 端口的临时脚本，且其工作目录在视频制作文件夹下；控制台判定漂移时仅根据 cwd 匹配，误将 9999 当成视频工坊的漂移端口并重定向入口

## 三、方案设计与技术决策
清理 9999 端口残留进程；在 server.py 的端口漂移探测中增加 strict_for_drift 严格匹配校验，杜绝仅凭 cwd 误判无关进程；平滑重启控制台并重新拉起 8088 视频工坊服务

## 四、核心实现与变更范围
- `onfig/projects.json`
- `server.py`

## 五、测试验证与客观证据
测试命令: `Invoke-WebRequest -Uri http://127.0.0.1:8088/`
结果:
```text
HTTP 200 OK，页面正常渲染；控制台项目状态恢复为 running 8088，port_drift 为 false
```

## 六、踩坑记录与问题沉淀
探测端口漂移时不能仅根据进程工作目录 cwd 判断归属，必须严格比对可执行程序或命令特征
