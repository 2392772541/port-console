# 开发档案：产品体验全面升级、根治端口漂移误报与双模块统一外壳重构

- **项目标识**：port-console & AI-Skills Web
- **归档时间**：2026-11-18 10:14:00

## 一、需求背景与目标
以产品经理视角全面审查「本机工作台（`http://127.0.0.1:8787`）」，根治跨项目端口漂移假阳性误报、端口冲突排障断头路、双前端外壳切换割裂、轮询阻塞与审计日志污染等核心问题，并通过浏览器模拟真实用户完成全流程点击验收。

## 二、现象排查与根因分析
1. **伪端口漂移大面积误报**：旧版 `is_owned_by_project` 将启动命令中的通用参数（如 `/c`、`/d`、`run`、`dev`、`127.0.0.1`）作为子串匹配特征，导致 `language_server.exe` (`41562`)、`tunnel-client.exe` (`14830`)、`cloudflared.exe` (`20241`) 被误认领给多个未启动项目；且自定义代理路径（如 `8787/skills`）被 `derive_effective_url` 错误覆写为 `:8765/skills`。
2. **外部端口冲突状态失真**：项目配置端口被外部无关目录进程占用时（如 `MuseFlow` 的 `8766` 被 `D:\hark-bridge` 占用），旧逻辑未核对进程归属即判定为 `running`，且禁用了停止与排障手段。
3. **扫描与体检性能瓶颈**：每次采集端口冷启动 PowerShell 执行两次 WMI 查询（耗时 ~4.3s），目录扫描未缓存且循环重复执行跨进程属性读取，导致首屏与环境体检耗时长达 13~35 秒。
4. **双模块外壳与 UI 体验割裂**：`/#ports` 与 `/skills` 侧边栏菜单不对称（缺失 `操作记录` 或 `技能变更`）、Logo 跳变、窄列文字竖排折行、未启动服务仍暴露报错外链、操作记录被 `GET` 轮询刷屏、多副本技能无法区分目录、空收藏误出「清空筛选」按钮及内联样式触发 CSP 报错。

## 三、核心实现与变更范围
- `E:\工程项目\codex项目合集\个人用\port-console\server.py`：重构进程归属签名提取与严格漂移守卫；识别外部端口占用冲突并提供安全释放接口 `/api/ports/release-conflict` 与日志查看接口 `/api/projects/<id>/logs`；改用 `psutil` 进程内采集套接字 + 服务/清单缓存 + 启动异步预热；过滤常规 `GET` 轮询日志并聚合多行记录。
- `E:\工程项目\codex项目合集\个人用\port-console\static\{index.html,app.js,styles.css}`：统一 `01~08` 单外壳导航与中文原生微标题；新增「端口冲突」筛选、「包含未登记监听端口」透视开关、「日志」弹窗与结构化中文操作审计列表；清零全部 CSP 内联样式报错与排版挤压问题。
- `D:\AI-Skills\web\static\{personal.html,personal.js,personal.css}`：像素级对齐工作台侧边栏外壳；同名多副本卡片展示来源目录徽章与副本切换提示；修复收藏页空状态、0 技能空分类置灰、变更记录连续重复折叠与搜索分页。
- `E:\工程项目\codex项目合集\个人用\port-console\tests\test_server.py`：新增通用词防误报、代理 URL 保留及外部冲突识别回归单元测试。

## 四、测试验证与客观证据
- 自动化单元测试：`port-console` 34/34 通过，`AI-Skills/web` 13/13 通过（共 47 项全绿）。
- 浏览器真人路径实测：`01~08` 全页面交互顺畅，首屏核心接口加载降至 `~361 ms`，全流程浏览器 Console `0` JS/CSP 报错。
